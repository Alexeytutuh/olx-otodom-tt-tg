# Бот «OLX + Otodom → Telegram → TikTok» для оренди у Вроцлаві

## Що робить
* Кожні 5 хвилин за годинником (о :00, :05, :10…) перевіряє **OLX** і **Otodom**: нові оголошення про
  оренду **цілих квартир у Вроцлаві від власників**, 1–3 кімнати, будь-яка ціна і площа. Типи будинку:
  blok, plomba, szeregowiec, apartamentowiec або не вказано. Kamienica, dom і loft відкидаються.
  Оголошення агентств і прихованих посередників фільтруються.
* Кожне нове оголошення надсилає **один раз**:
  1. альбом до 10 фото, а в підписі готовий пост польською у форматі друга
     (`Kawalerka | 35 m² | taras`, `WYNAJEM`, ціна, czynsz, `Razem` тощо). Якщо текст довший за 1024
     символи, він іде окремим повідомленням;
  2. під ним коротка картка українською: джерело з посиланням, тип будинку, час публікації,
     позначки на кшталт «⚠️ Можливий дубль». На картці дві кнопки.
  У кінці поста — контакти рієлтора з `POST_FOOTER` (`.env`).
* Рядки поста, для яких немає даних, не показуються. `Razem` дорівнює сумі відомих чисел
  (ціна + czynsz/media + garaż + prąd) і з'являється, лише коли, крім ціни, відомо ще щось.
  «w cenie» показується як «w cenie» і в суму йде як 0.
* Однакове оголошення з двох сайтів надсилається один раз: імпорт Otodom → OLX і той самий текст з тією
  ж ціною. Якщо збіг лише схожий (ціна, площа, кімнати, вулиця, заголовок, перше фото), оголошення
  приходить з позначкою «можливий дубль» і як відповідь на попередній пост.

## Кнопки
* **🎬 Згенерувати**: за 10–20 с приходять слайди для TikTok **файлами**, щоб iPhone не стискав якість:
  1080×1920 JPEG, до 10 штук. Перший слайд має оранжеві плашки «Kawalerka | 35 m² | Wrocław (район)»
  і внизу головну перевагу (Taras/Balkon/Ogródek/Garaż) або ціну. На інших слайдах фото цілком на
  розмитому фоні. Після файлів приходить текст для TikTok (пост без першого рядка, без хештегів),
  під ним кнопки **📢 В канал** (альбом + пост у `TELEGRAM_CHANNEL_ID`) і **🎵 В чернетки TikTok**
  (через сервіс tiktok-connect). Натиснута кнопка стає ✅, повторне натискання не дублює.
* **🏢 Посередник**: продавець потрапляє в чорний список, і його оголошення більше не приходять
  (з будь-якого акаунта з тим самим текстом). Картка змінюється, на ній з'являється кнопка
  **↩️ Не посередник** для скасування.

## Команди
| Команда | Що робить |
|---|---|
| `/start` | Перший, хто надіслав, стає власником: оголошення йдуть у цей чат |
| `/status` | Остання перевірка OLX і Otodom, помилки, скільки надіслано сьогодні і всього, розмір чорного списку |
| `/pause` | Пауза: перевірки тривають, але нічого не надсилається і не накопичується |
| `/resume` | Зняти паузу |
| `/blacklist` | Список посередників; натисни на запис, щоб зняти позначку |
| `/unblock N` | Зняти позначку з запису №N |

## Сповіщення (у `ALERT_CHAT_ID` або власнику)
* «⚠️ OLX відвалився: <причина>» приходить після 3 невдалих перевірок поспіль (~15 хв), повтор
  не частіше разу на 6 год. «✅ OLX знову працює» приходить, коли перевірка відновилась. Для Otodom так само.
* «✅ Telegram знову доступний» приходить після збоїв зв'язку з Telegram. Самі збої лише пишуться в лог,
  бо повідомити через Telegram, який не працює, неможливо.
* «♻️ Бот перезапустився після зависання» з'являється, якщо спрацював внутрішній сторож.
* «⚠️ Внутрішня помилка…» приходить, якщо перевірки 3 рази поспіль падають через помилку в коді.

## Перший запуск
Перший прогін **тихий**: усі поточні оголошення (~50–70) позначаються як бачені й не надсилаються.
Потім приходить «✅ Бот запущено, стежу за OLX і Otodom», і далі надсилаються лише нові.

## Як змінити критерії
Усі критерії пошуку лежать у файлі `parsers/config.py`:
* `ROOMS_MIN`/`ROOMS_MAX`: кількість кімнат (зараз 1–3);
* `PRICE_MIN_PLN`/`PRICE_MAX_PLN`, `AREA_MIN_M2`/`AREA_MAX_M2`: межі ціни й площі (`None` означає без обмеження);
* `BUILDING_ALLOWED`/`BUILDING_EXCLUDED`/`ALLOW_UNKNOWN_BUILDING`: типи будинків;
* `NEW_MAX_AGE_HOURS`: що вважати «новим» (48 год);
* `AGENT_PATTERNS`, `SELLER_NAME_AGENT_PATTERNS`: слова й імена, за якими розпізнаються агентства.

Після зміни на сервері: `cd /opt/olx-tiktok-bot && docker compose up -d --build` (користувач у групі `docker`, sudo не потрібен).

Текст поста налаштовується в `olxbot/formatting.py`: речення-шаблони в `template_sentence`, рядок
`PL | UA | RU | EN`; контакти в кінці — `POST_FOOTER` у `.env`. Вигляд слайдів (колір плашок, шрифт, розміри, позиції)
налаштовується в `olxbot/slides.py`, у словнику `STYLE`. Інтервал, сповіщення й доступ задаються в `.env`
(див. `.env.example`).

## Будова
| Шлях | Що це |
|---|---|
| `parsers/` | Парсери OLX і Otodom (окремий модуль; у 1.1.0 змінено `extract.py`: сума з іншого речення) |
| `olxbot/app.py` | Розклад, обробка оголошень, команди, кнопки |
| `olxbot/formatting.py` | Пост (PL), картка (UA), підпис TikTok, тексти для плашок |
| `olxbot/slides.py` | Генератор слайдів TikTok (окремий модуль) |
| `olxbot/tiktok_hook.py` | Клієнт tiktok-connect для кнопки «В чернетки TikTok» (`TIKTOK_CONNECT_*` у `.env`) |
| `olxbot/streets.py`, `olxbot/data/wroclaw_streets.txt` | Довідник вулиць Вроцлава (OpenStreetMap) для повних назв |
| `olxbot/dedupe.py`, `images.py` | Пошук дублів (зокрема dHash першого фото) |
| `olxbot/storage.py` | SQLite (WAL) у `data/bot.sqlite3`: бачені id (30 днів), пости, чорний список, пам'ять текстів агентів, стан |
| `olxbot/telegram.py` | Клієнт Bot API: ліміти, retry_after, повтори |
| `olxbot/runtime.py` | Heartbeat, сторож зависань, systemd notify |
| `tests/`, `tools/` | Тести, фейковий Telegram-сервер, e2e, рендер прикладів |
| `deploy/olx-tiktok-bot.service` | Альтернатива Docker через systemd |

Тести: `PYTHONPATH=. python -m unittest discover -s tests -t .`. Живий e2e з фейковим Telegram:
`python tools/e2e_live.py`.

## Обмеження
* Kaucja і дата заїзду на OLX беруться з тексту опису: вдається для ~50–60% оголошень. Якщо даних немає,
  рядка просто немає.
* Вулиця з тексту OLX іноді в родовому відмінку. Найчастіші закінчення бот виправляє
  («Braterskiej» → «ul. Braterska»), але не всі.
* Головна перевага (taras/balkon/ogródek/garaż) визначається за словами в описі, тому можливі
  рідкісні помилки.
* Розпізнавання агентів і дублів евристичне. Для агентів, які проскочили, є кнопка «🏢 Посередник».
* Від появи оголошення до повідомлення в середньому 3–8 хв (опитування раз на 5 хв плюс затримка OLX/Otodom).
